# Sağlık & Wellness Kitaplığı | PHP Web Projesi

PHP ve MySQL kullanılarak geliştirilmiş, sağlık, kişisel gelişim ve sağlıklı yaşam konularındaki kitapların keşfedilmesini sağlayan dinamik bir web platformudur.

Bu proje, Web Tasarımı ve Programlama dersi kapsamında web geliştirme, kullanıcı arayüzü tasarımı, veritabanı yönetimi ve dinamik web sayfaları oluşturma becerilerini geliştirmek amacıyla hazırlanmıştır.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL / MariaDB
- PDO (PHP Data Objects)
- XAMPP
- Visual Studio Code

## Projenin Özellikleri

- Sağlık ve kişisel gelişim kitaplarının listelenmesi
- Kitapların kategorilere göre filtrelenmesi
- Kitaplara ait detay sayfalarının görüntülenmesi
- Kullanıcı kayıt ve giriş işlemleri
- Oturum yönetimi ve kullanıcı çıkış işlemleri
- Kullanıcıların kitapları favorilerine ekleyebilmesi ve favorilerinden çıkarabilmesi
- İletişim formu aracılığıyla mesaj gönderilmesi
- Veritabanı üzerinden kitap ve kullanıcı bilgilerinin yönetilmesi
- CSS ve JavaScript ile geliştirilmiş etkileşimli web arayüzü

## Projenin Amacı

Bu projede, kullanıcıların sağlık ve kişisel gelişim alanındaki kitaplara kolayca ulaşabilecekleri bir web platformu geliştirilmesi hedeflenmiştir.

PHP ile sunucu taraflı işlemler gerçekleştirilmiş, MySQL veritabanı kullanılarak kitap bilgileri ve kullanıcı işlemleri yönetilmiştir.

Proje sayesinde frontend ve backend geliştirme süreçleri bir arada uygulanmıştır.

## Projenin Çalıştırılması

1. Bilgisayarınıza XAMPP kurun.
2. XAMPP üzerinden Apache ve MySQL servislerini başlatın.
3. `saglik_kitaplari` proje klasörünü `xampp/htdocs` dizinine yerleştirin.
4. `http://localhost/phpmyadmin` adresinden `saglik_kitaplari` isimli veritabanını oluşturun.
5. Kişisel veri içermeyen örnek SQL dosyasını veritabanına aktarın.
6. `veritabani.php` dosyasındaki bağlantı ayarlarını kendi yerel ortamınıza göre düzenleyin.
7. Tarayıcınızda `http://localhost/saglik_kitaplari/anasayfa.php` adresini açın.

## Not

Bu proje eğitim amacıyla geliştirilmiş bir web uygulamasıdır. Gerçek kullanıcı verileri içermeyen örnek bir veritabanıyla çalıştırılması önerilir. Canlı ortamda kullanılmadan önce güvenlik ve veri koruma açısından ek geliştirmeler yapılmalıdır.
